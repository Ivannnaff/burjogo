# BurjoGo - Sistem Pemesanan Online

Aplikasi web pemesanan makanan dan minuman ala warung Burjo dengan dukungan sistem backend PHP dan panel admin.

## Fitur Utama
- **Landing Page & Katalog Menu:** Beranda interaktif dengan kategori (Makanan, Minuman, Snack).
- **Keranjang Belanja:** Pengelolaan item pesanan menggunakan LocalStorage.
- **Checkout & Dine-In:** Konfirmasi pesanan dengan nomor meja dan catatan.
- **Panel Admin:** Manajemen data pesanan dan menu (PHP & Database).

## Teknologi yang Digunakan
- **Frontend:** HTML5, CSS3, JavaScript, Feather Icons
- **Backend:** PHP, MySQL (Koneksi & Manajemen Pesanan)
- **Environment:** Web Server (Apache/Nginx/XAMPP)
